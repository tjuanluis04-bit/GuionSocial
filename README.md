# Guiones sociales

App Android (Kotlin + Jetpack Compose) con guiones para decir en situaciones sociales.

## Compilar en GitHub Actions
1. Crea un repositorio y sube todo el contenido de esta carpeta (incluida `.github`).
2. En la pestaña **Actions** se ejecuta «Compilar APK» (o lánzalo con *Run workflow*).
3. Al terminar, descarga el artefacto **GuionesSociales-apk** e instala el `.apk`.

## Uso
- **Nuevo guion**: título, categoría, imagen opcional y texto (una frase por línea).
- **Frase a frase**: ensaya avanzando una frase cada vez.
- **Fijar en la pantalla de bloqueo**: notificación persistente con botones Anterior / Siguiente / Quitar.
- **Widget**: mantén pulsada la pantalla de inicio → Widgets → Guiones sociales.
